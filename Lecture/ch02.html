2.1 어텐션 기본 원리

어텐션은 "흐릿한(soft) 딕셔너리"다

🎬 비유 — 영화 추천

보통 딕셔너리는 키가 정확히 일치해야 값을 찾습니다. 하지만 영화 취향은 딱 떨어지지 않죠. "액션 6, 드라마 4, 코미디 5"인 새 영화를 평가하고 싶다면, 기존 영화들 중 취향이 비슷한 영화일수록 더 큰 비중을 두고 그 평점들을 섞어서 예측하면 됩니다. 이것이 바로 어텐션의 핵심 아이디어입니다.

def soft_dictionary(query, dictionary):
    similarity = [dot(query, key) for key in dictionary]   # 유사도
    weights = softmax(similarity)                            # 비율로 정규화
    return sum(w * v for w, v in zip(weights, dictionary.values()))
2.2 어텐션의 수식과 구현

Query, Key, Value — 세 가지 역할

📚 비유 — 도서관 사서

Query(질문): 내가 사서에게 하는 질문 ("SF 로맨스 소설 찾아줘").
Key(색인): 책마다 붙어있는 요약 키워드 카드.
Value(내용): 그 책이 실제로 담고 있는 내용.
질문과 색인이 비슷할수록 그 책의 내용을 더 많이 참고합니다.

def attention(Q, K, V):
    similarity = Q @ K.T                    # 질문·색인 유사도
    weights = softmax(similarity, dim=1)    # 비율로 정규화
    output = weights @ V                    # 내용을 가중합
    return output

실제 모델에서는 Q, K, V 모두 입력 x에 각각 다른 학습된 변환 행렬(W_q, W_k, W_v)을 곱해 만들어냅니다.

2.3 어텐션 스케일링

왜 √d로 나눌까?

차원 수(d)가 커지면 Q·K의 내적 값도 커지고 분산이 커집니다. 그러면 softmax가 한쪽으로 극단적으로 쏠려버립니다.

softmax([100, 200, 300]) ≈ [0, 0, 1]   # 사실상 한 곳만 선택 (원-핫)
scores = (Q @ K.T) / sqrt(d)  # 분산을 일정하게 유지
🎤 비유 — 마이크 볼륨

여러 사람이 동시에 말할 때 한 사람만 마이크를 세게 잡으면 그 목소리만 들리고 나머지는 묻혀버립니다. √d로 나누는 것은 모든 목소리 크기를 적당히 조절해, 여러 단어의 정보를 골고루 반영할 수 있게 하는 볼륨 조절 장치입니다.

2.4 – 2.5 트랜스포머 구조 & 위치 인코딩

순서를 모르는 모델에게 순서를 알려주기

🗂️ 비유

어텐션 계산만 보면 트랜스포머는 단어들을 뒤섞인 카드 더미처럼 다룹니다 — "누가 몇 번째인지" 신경 쓰지 않습니다. 그래서 위치 인코딩(position embedding)이라는 순서 스티커(1번, 2번, 3번…)를 각 단어 임베딩에 더해줘야 순서 정보를 알 수 있습니다.

emb     = self.embed(ids)               # 토큰 자체의 의미
pos_emb = self.pos_embed(positions)     # 몇 번째 위치인지
x = emb + pos_emb                       # 두 정보를 더해 입력으로 사용
2.6 어텐션 마스크

미래를 훔쳐보지 못하게 가리기

📝 비유 — 시험 답안지 가리개

다음 단어를 맞히는 연습을 하는데 이미 정답(미래 단어)을 볼 수 있다면 반칙이겠죠? 인과적 마스크(causal mask)는 각 위치가 자기 자신과 그 이전 토큰만 보게 하고, 뒤쪽은 확률 0(−∞)으로 가려버립니다.

mask = torch.tril(torch.ones(C, C))                 # 하삼각행렬: 과거만 1
scores = scores.masked_fill(mask == 0, float('-inf'))
weights = softmax(scores, dim=-1)                   # 미래 위치 가중치는 0이 됨
2.7 밸류 변환 행렬 효율 개선

짐을 압축해서 옮기고, 도착해서 다시 풀기

🧳 비유

Value를 처음부터 큰 차원(embed_dim)으로 만들면 계산이 무겁습니다. 대신 작은 캐리어 (key_dim)에 압축해서 어텐션 연산을 마친 뒤, 도착지에서 W_o로 다시 원래 크기로 풀어놓으면 파라미터 수를 크게 줄일 수 있습니다.

V = self.W_v(x)                 # embed_dim → key_dim (압축)
hidden = weights @ V            # 어텐션 계산은 key_dim에서
output = self.W_o(hidden)       # key_dim → embed_dim (다시 복원)
2.8 멀티헤드 어텐션

여러 전문가가 동시에 회의하기

🧑‍🤝‍🧑 비유 — 전문가 회의

문장 하나를 분석할 때 문법 전문가, 의미 전문가, 감정 전문가가 동시에 각자의 관점으로 살펴본 뒤 의견을 모으면 더 풍부한 이해가 가능합니다. 멀티헤드 어텐션은 Q·K·V를 여러 개의 작은 "헤드"로 나눠 각기 다른 관점의 어텐션을 병렬로 계산하고, 마지막에 그 결과를 이어붙여 다시 합칩니다.

Q = Q.view(B, C, H, D).transpose(1, 2)  # (B, H, C, D) — H개의 헤드로 분할
... 각 헤드마다 독립적으로 어텐션 계산 ...
hidden = hidden.transpose(1, 2).view(B, C, H*D)  # 다시 하나로 합침
output = self.W_o(hidden)

n_head=8, head_dim=64라면 embed_dim=512인 셈입니다.

2.9 트랜스포머 블록

컨베이어 벨트 + 회의실 + 개인 책상

🏭 비유

블록은 잔차 연결(residual)로 원본 정보를 컨베이어 벨트처럼 계속 흘려보내면서, 그 위에 가공 결과를 "더해나갑니다". 어텐션은 토큰들끼리 정보를 주고받는 회의실이고, FFN(피드포워드)은 각 토큰이 혼자 책상에 앉아 생각을 정리하는 단계입니다.

x = x + self.attn(self.norm1(x))   # 회의: 토큰끼리 정보 교환 + 원본 유지
x = x + self.ffn(self.norm2(x))    # 개인 작업: 토큰별 심화 처리 + 원본 유지

LayerNorm은 사진 보정에서 밝기·명암을 일정한 범위로 맞추듯, 값의 스케일을 매번 정돈해 학습을 안정시킵니다.

2.11 정리

2장 핵심 요약

  • 어텐션 = 유사도 기반으로 값을 가중합하는 "소프트 딕셔너리"
  • Q(질문) · K(색인) · V(내용), √d 스케일링으로 softmax 극단화 방지
  • 인과적 마스크로 미래 토큰 참조를 차단 → 다음 토큰 예측 과제에 적합
  • 멀티헤드 = 여러 관점을 병렬로 분석, 잔차 연결 + LayerNorm으로 깊게 쌓아도 안정적 학습
  • 블록을 여러 층 쌓고 임베딩을 공유하면 GPT-2 구조 완성

QUIZ 1

어텐션 점수를 √d로 나누는 이유는?

정답: 두 번째. 차원이 커질수록 내적 값의 분산이 커져 softmax가 원-핫에 가까워지는데, √d로 나누면 분산이 일정하게 유지됩니다.
QUIZ 2

인과적 마스크(causal mask)는 무엇을 막기 위한 장치인가요?

정답: 첫 번째. 다음 토큰 예측 과제에서 미래를 미리 보면 "반칙"이 되므로, 마스크로 과거·현재 위치만 참조하도록 제한합니다.
