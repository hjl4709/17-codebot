0.1

LLM은 사람이 언어를 배우는 과정과 닮았다

눈·귀로 언어를 받아들이고, 두뇌로 이해하고 예측하고, 오랜 교육을 거쳐 똑똑해지는 과정 — LLM도 똑같이 토크나이저 · 모델 · 학습 세 가지로 이루어져 있습니다.

구성 요소 ① 토크나이저

텍스트를 숫자로 바꾸는 통역사

🗣️ 비유

컴퓨터는 글자를 모릅니다. 오직 숫자만 계산할 수 있죠. 토크나이저는 "안녕하세요"같은 문장을 컴퓨터가 다룰 수 있는 숫자 번호표(토큰 ID)로 바꿔주는 동시통역사입니다. 모델이 답을 내놓으면, 다시 숫자를 사람이 읽을 수 있는 글자로 되돌려줍니다.

→ 1장에서 문자 단위부터 BPE까지, 이 통역사를 직접 만들어봅니다.

구성 요소 ② 모델

다음 토큰을 예측하는 빈칸 채우기의 달인

🧠 비유

모델(트랜스포머)은 지금까지 나온 단어들을 보고 "다음에 올 단어는 무엇일까?"를 끊임없이 추측하는 초고속 빈칸 채우기 선수입니다. 이 추측을 한 글자씩 반복하면 어느새 하나의 문장, 하나의 코드가 완성됩니다.

→ 2장에서 이 "추측 엔진"의 핵심 부품인 어텐션과 트랜스포머 구조를 뜯어봅니다.

구성 요소 ③ 학습

추측을 점점 잘하게 만드는 교육 과정

🎓 비유

처음의 모델은 아무렇게나 추측하는 신입생과 같습니다. 학습은 "정답과 얼마나 다른가"(손실)를 계산해서, 모델 내부의 수많은 파라미터(가중치)를 아주 조금씩 정답 쪽으로 고쳐나가는 과정입니다. 이걸 수만 번 반복하면 실력이 쌓입니다.

→ 3장에서 이 교육 과정을 사전 학습 → SFT → 강화 학습 3단계로 나눠 실습합니다.

0.2 LLM의 사전 학습

사전 학습 = 다독(多讀)으로 세상 상식 쌓기

📖 비유

인터넷의 방대한 글(코드, 위키, 뉴스 등)을 모델에게 보여주며 "다음 단어 맞히기" 게임을 수십억 번 반복시킵니다. 특정 과목을 콕 집어 가르치는 게 아니라, 엄청난 양의 책을 닥치는 대로 읽히면서 언어의 규칙과 세상의 상식을 저절로 흡수하게 만드는 것과 같습니다.

  • 정답 라벨을 사람이 일일이 달 필요가 없음 — 원문 자체가 정답(다음 글자)
  • 그래서 자기지도학습(self-supervised)이라 부름
  • 결과물: 문법·상식은 있지만 아직 "대화 예절"은 모르는 모델
0.3 LLM의 사후 학습

사후 학습 = 신입사원 실무 코칭

💼 비유

다독을 마친 모델은 아는 건 많지만, 질문에 대답하는 형식·태도를 모르는 신입사원과 같습니다. 사후 학습은 이 신입사원을 실전에 투입할 수 있게 코칭하는 단계로, 두 단계로 이뤄집니다.

① SFT (지도 파인튜닝)

"질문에는 이렇게 답하세요"라는 모범 답안집을 보여주며 대화 포맷과 태도를 따라 하게 만드는 과외 수업.

② 강화 학습 (RL)

직접 여러 번 답을 시도해보고, 잘한 시도는 칭찬(보상)해서 그런 행동을 더 하도록 스스로 연습시키는 실전 트레이닝.

사전 학습 vs 사후 학습, 한눈에 비교

사전 학습 (Pre-training)사후 학습 (Post-training)
비유다독으로 상식 쌓기신입사원 실무 코칭
목표언어·세상 지식 습득대화 형식·유용성·안전성 개선
데이터방대한 원문 텍스트사람이 정리한 질문-답변 쌍, 보상 신호
방법다음 토큰 예측SFT(모방) + RL(시행착오)
비용매우 큼 (가장 오래 걸림)상대적으로 작음
Part I

CodeBot 만들기 — 개발 흐름

Part I에서는 코드를 짜주는 미니 챗봇, CodeBot을 토크나이저부터 강화 학습까지 밑바닥부터 직접 만듭니다.

I.1 개발 흐름

CodeBot이 태어나는 4단계

1
토크나이저 학습 — TinyCodes 데이터로 BPE 어휘(1,000개)를 학습해 통역사를 준비 (1장)
2
사전 학습 — GPT-2 구조 모델에 코드 데이터를 "다음 토큰 맞히기"로 반복 학습 (2·3장)
3
SFT — Instruction-Response 형식 예시로 대화 포맷을 가르침 (3장)
4
강화 학습 (GRPO) — 스스로 답을 여러 번 생성해보고 보상으로 다듬음 (3장)

이 파이프라인은 codebot/ 폴더의 실제 코드로 실습합니다.

이 책의 세 프로젝트

CodeBot

Part I · 기본편
코드를 생성하는 미니 챗봇. 핵심 원리를 처음부터 끝까지 가장 단순한 형태로 구현.

StoryBot

Part II · 응용편
이야기를 만드는 챗봇. RoPE, SwiGLU, AdamW, DPO 등 실전 기법을 더함.

WebBot

Part III · 도전편
더 큰 규모의 챗봇. FlashAttention, MoE, 분산 학습 등 최신 기법으로 확장.

난이도와 규모가 점점 커지는 3단 로켓 구조입니다.

정리

0장 핵심 요약

  • LLM = 토크나이저(통역사) + 모델(빈칸 채우기 엔진) + 학습(교육 과정)
  • 사전 학습: 방대한 텍스트로 다음 토큰 맞히기 → 언어·상식 습득 (다독)
  • 사후 학습: SFT(모범답안 모방) + RL(시행착오로 개선) → 실전 대화 능력 (코칭)
  • Part I은 CodeBot을 토크나이저 → 사전 학습 → SFT → 강화 학습 순서로 완성
➡️ 다음 시간

1장 토크나이저: 문자 단위 → 바이트 단위 → BPE까지, "통역사"를 직접 만들어봅니다.

QUIZ 1

사전 학습(pre-training) 단계에서 정답 라벨은 누가 만드나요?

정답: 두 번째. 사전 학습은 방대한 원문에서 "다음 토큰"을 정답으로 삼기 때문에 사람이 따로 라벨링할 필요가 없는 자기지도학습입니다.
QUIZ 2

SFT와 강화 학습(RL)의 차이를 가장 잘 설명한 것은?

정답: 두 번째. SFT는 예시를 따라 하는 모방 학습, RL은 직접 답을 생성해보고 보상 신호로 확률을 조정하는 시행착오 학습입니다.
